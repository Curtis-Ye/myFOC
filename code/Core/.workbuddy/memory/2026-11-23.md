## FOC 速度环低速抖动诊断（仅分析，未改源码）

- 现象：低速运行电机一振一振，调试界面速度上蹿下跳，调整 PI 参数无效。
- 架构：main.c 主循环阻塞式 I2C(400 kHz) 轮询 AS5600 写 current_angle；TIM3 2 kHz 中断里 get_velocity() + velocity_control() + FOC_control()；电压模式 FOC（Uq 直接给占空比），无电流环；POLE_PAIRS=7；TIM1 ARR=1799 → PWM 40 kHz；CTRL_FREQ_HZ=2000，VEL_DIV=20 → 测速/速度环 100 Hz。
- 根因（按优先级）：
  1. control.c:55 `elec_angle_offset = 0` 未标定（注释自己也写"默认 0 = 未校准"）。7 对极下 ±12.86° 机械偏差 = ±90° 电角度，力矩系数 cosΔθ 下降甚至变号，速度环可能局部正反馈。
  2. main.c:21 encoder_task() 与中断异步，角度无时间戳；control.c:136 get_velocity() 只取窗口两端瞬时角差 / 名义 10 ms，端点落在哪一帧 I2C 采样随机。AS5600 12 bit，1 LSB = 0.088° → 速度分辨率 8.8 °/s，低速 20 °/s 时量化占 44%；低通 α=0.5（τ≈14 ms）压不住。
  3. 电角度每 0.5 ms 重算但用的是旧角度，×7 把 1 LSB 放大成 0.62° 电角度台阶，无角度外推 → 电压矢量相位阶跃 → 转矩脉动。
  4. PID.c:30 `integral += error` 无 dt，100 Hz 下等效连续 Ki = Ki×100；低速分支 pid_velocity2 Ki=1.0 → Ti = Kp/(Ki·fs) ≈ 50 ms，比反馈滞后（10 ms 窗口 + ~14 ms 低通）还快 → 低频极限环。
  5. PID.c:45-51 输出限幅到 ±6000 时没有冻结积分（注释称"天然抗饱和"是错的，那只限了 sum_error 本身）；integral_limit=5000 × Ki=1 → 积分项独占 83% 输出，反向退出约需 1 s → windup 大幅摆动。
  6. control.c:212 `target<=1000` 反而走 Ki=1.0 的强积分；两套 PID 切换无 bumpless transfer。
  7. 次要：usart.c data_process() 每主循环 atof(rx_buffer)，rx_complete 从未检查，串口中断逐字节写时可能读到半帧；无电流环使低速齿槽/静摩擦无法抑制。
- 建议顺序：开环低频分界 → 标定 offset 与 uq_sign → VEL_DIV 临时改 100 验证量化 → encoder_task 改累加式测速（每帧累加 angle_diff，窗口边界读累计量并清零）/加时间戳 → PID 加 dt + 条件积分抗饱和 + 统一参数 → 电角度按速度外推 → 中期加电流环或换高分辨率 SPI 编码器。
