# 2026-11-21

## delta_angle 调试窗口恒为 0 的诊断与修复
- 用户回退了 11-20 的 I2C 单点采样方案，改为 float 角度制（current_angle / last_angle 单位都是度），并把 delta_angle 提升为全局量便于观察。
- 根因：main.c 的 TIM3 回调里先 `last_angle = current_angle;` 再 `delta_angle = current_angle - last_angle;`，顺序颠倒 → 差值恒为 0，与电机是否转动无关。且用户写的 get_raw_velocity() 全工程无调用点，归一化/死区逻辑从未执行。
- 次因：死区 `±1` 的单位从 LSB 变成「度」后等于 ±1 度，会吃掉手转的微小角度差；工程 `<Optim>4</Optim>` 下 delta_angle 非 volatile，调试器可能读到滞后值。
- 修复（3 个文件）：get_raw_velocity() 改为「先算差 → 归一化 → 更新 last_angle → delta_angle 存原始差值 → 死区只作用于速度输出(0.1°)」；中断改为调用 get_raw_velocity() 并存入新增的 g_velocity；delta_angle 加 volatile；control.h 注释同步。
- 编译验证：Keil UV4 -j0 -b → 0 Error / 0 Warning，Code=18212 RO=776 RW=92 ZI=2044。
- 关键设计：delta_angle 保留未经死区的原始角度差供调试观察，静止时会有 ±0.088°(1 LSB) 的正常抖动；g_velocity 经死区平滑，静止为 0。
- 残留架构风险：current_angle 仍由主循环 encoder_task() 阻塞式读 I2C 更新，与 TIM3 2kHz 中断不同步，delta 会间歇为 0/跳动；上一轮的 I2C 单点采样方案已被用户回退。
- 物理限制：每周期测速下 1 LSB(0.088°) 对应 176°/s，硬死区必然吃掉低速；做速度环建议改分频累计测速 + 低通滤波。
